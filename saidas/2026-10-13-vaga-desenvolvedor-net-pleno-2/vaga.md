# Desenvolvedor .NET Pleno

Buscamos um(a) Desenvolvedor(a) .NET Pleno colaborativo(a), organizado(a) e com perfil investigativo para transformar necessidades de negócio em integrações confiáveis. REMOTO

## Responsabilidades e Atribuições
* Desenvolver e manter integrações entre sistemas utilizando C#/.NET e ASP.NET Core Web API.
* Compreender o fluxo de ponta a ponta das integrações para implementar e ajustar cada etapa.
* Construir e consumir APIs REST, seguindo os contratos de requisição e resposta definidos com as equipes envolvidas.
* Desenvolver integrações com bancos de dados relacionais, utilizando SQL e Entity Framework Core ou equivalente.
* Publicar e consumir mensagens em filas, tratando situações comuns como reprocessamento e mensagens duplicadas.
* Aplicar os mecanismos de resiliência já adotados pelo time, como retry e timeouts.
* Investigar falhas que atravessem diferentes sistemas, utilizando logs e rastreio de requisições para identificar a origem do problema.
* Trabalhar com Git, pull requests e revisão de código, mantendo a documentação das integrações atualizada.
* Zelar para que dados sensíveis não trafeguem indevidamente entre sistemas.

## O que amplia as suas chances
* Experiência com plataforma de integração (iPaaS), especialmente Digibee.
* Conhecimento de CQRS, DDD, arquitetura em camadas e injeção de dependência.
* Experiência com sistemas legados.
* Vivência com ERP/CRM, como Protheus, Dynamics ou equivalentes
* Conhecimento de padrões de integração como outbox, idempotência, reconciliação e versionamento de contratos.

## O que não pode faltar
* Experiência mínima de 3 a 4 anos com desenvolvimento em C# e .NET 8 ou superior, incluindo vivência prática com programação assíncrona (async/await) em projetos em produção.
* Experiência comprovada com ASP.NET Core Web API, tendo atuado no desenvolvimento e consumo de APIs REST.
* Domínio dos fundamentos de HTTP (métodos, códigos de status, cabeçalhos...).
* Vivência com banco de dados relacional (SQL Server, PostgreSQL ou similar), incluindo modelagem, escrita de queries complexas, controle de transações.
* Uso de Entity Framework Core ou ORM equivalente em projetos.
* Experiência de trabalho em equipe usando Git em fluxo colaborativo (pull requests, code review).

## Desejável
* Conhecimento de mensageria, preferencialmente RabbitMQ ou similar, e de conceitos de resiliência (retry, timeout, circuit breaker).
* Experiência com autenticação moderna com OAuth 2.0, OpenID Connect, JWT e Microsoft Entra ID (Azure AD).
* Conhecimento de observabilidade, log estruturado e rastreio de requisição.
* Vivência com testes automatizados utilizando xUnit e/ou Moq.
* Experiência com Azure DevOps, incluindo uso de pipelines de CI/CD e/ou gestão de work items.
* Conhecimento em documentação de APIs com OpenAPI/Swagger e/ou uso do Scalar.
* Familiaridade de LGPD aplicada a sistemas.
